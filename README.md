# My Portfolio

## Описание проекта

My Portfolio — персональный сайт-портфолио,
созданный с использованием HTML, CSS и JavaScript.

Сайт содержит информацию об авторе, навигацию
и основные разделы портфолио.

## Настройка разработки

1. Установить Visual Studio Code.
2. Установить Git.
3. Открыть папку проекта в VS Code.
4. Открыть файл index.html в браузере.

## Руководство по коммитам и веткам

При разработке проекта используются правила
оформления коммитов и работы с Git-ветками.
